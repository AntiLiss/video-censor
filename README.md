# Video Censor

Веб-приложение для автоматической цензуры видео с использованием ИИ.

## Описание

RESTful API на Django REST Framework, которое позволяет загружать видео и автоматически цензурировать нежелательный контент. Система поддерживает как визуальную, так и аудио цензуру.

## Основные возможности

### 🎥 Видео цензура (замыливание объектов)
- Цензурирование сцен с курением
- Цензурирование сцен с кровью и насилием

### 🔊 Аудио цензура (запикивание слов)
- Цензурирование нецензурной и грубой лексики на русском и английском языках
- Возможность добавления собственного списка слов для цензуры

### 👥 Система пользователей
- Регистрация и авторизация через JWT токены
- Интеграция с Google OAuth
- Профили пользователей

### 💳 Подписки и платежи
- Система подписок с различными планами
- Интеграция с платежной системой ЮKassa
- Автоматическое продление подписок
- Скидки при годовой подписке

## Технологии

- **Backend**: Django 5.0, Django REST Framework
- **База данных**: PostgreSQL
- **Очереди задач**: Celery + Redis
- **AI/ML**: Ultralytics (YOLO), Faster Whisper
- **Аудио обработка**: PyDub
- **Контейнеризация**: Docker & Docker Compose
- **Платежи**: ЮKassa API

## Быстрый старт

1. Клонируйте репозиторий
2. Создайте файл `.env` с необходимыми переменными окружения
3. Запустите с помощью Docker Compose:

```bash
docker-compose up --build
```

Приложение будет доступно по адресу: http://localhost:8000
